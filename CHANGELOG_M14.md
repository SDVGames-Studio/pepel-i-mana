# CHANGELOG M14 — большой этап (issue #3 «Делаем М14 и другие исправления»)

План этапа — 12 частей A–L (см. PLAN.md), приёмка по порядку. Каждая часть —
играбельная сборка в build/. Все 1708 автотестов зелёные.

## Часть A — Сейв/загрузка (v1.4.0, 2026-10-20)

Главная дыра проекта закрыта: игра сохраняется в файл и загружается целиком.

### Что сделано

- **Файл сейва**: `user://saves/save.json` — человекочитаемый JSON (легко
  дебажить), поле `v` с версией формата. Несовместимая версия, битый файл или
  мусор вместо JSON честно отклоняются с тостом («Сохранение сделано другой
  версией игры» и т.п.), игра не падает.
- **Сохраняется всё состояние**:
  - город — ландшафт целиком (сетка бит-в-бит: спиленные деревья/пни,
    посаженные саженцы, вскрытая руда с остатком прочности, дороги и износ
    троп), здания/стройки/зоны с кучами и прогрессом, ресурсы, жители целиком
    (черты, пары, настроение, навыки, болезни, возраст, ссылки на дом/работу),
    летопись, исследования, магическое загрязнение, гнев леса и тайная армия
    некроманта, время/день, скот, караваны, могилки;
  - мир — карта по тайлам, туман войны, все POI с состояниями
    (cleared_day/strength/nest/faction/state), день мира, следы, осады;
  - герой — рюкзак, гримуар, монеты, дерево навыков (XP/уровень/узлы),
    тайл и HP/мана.
- **UI**:
  - «Продолжить игру» в главном меню видна при наличии сейва (раньше — только
    пока сессия жива); битый сейв — сообщение в меню, кнопка гаснет;
  - «Сохранить игру» в оверлее паузы (Esc в городе и на карте мира);
  - автосейв каждое утро города (со 2-го дня) с тостом «Игра автоматически
    сохранена»;
  - после загрузки герой появляется на сохранённом месте с сохранённым HP.
- **Данжи транзитны** (конвенция честно показана в паузе данжа): середина
  данжа не сохраняется, автосейв в данже не работает; сохраняться можно из
  города и с карты мира.
- Векторные поля и словари с ключами-тайлами кодируются тегами (`v2`/`v2i`/
  `pv2`/`d`) — обратная загрузка восстанавливает типы GDScript (Vector2,
  PackedVector2Array, пути жителей).

### Файлы

- `scripts/save_game.gd` — новый модуль (сохранение/загрузка/кодирование).
- `scripts/game.gd` — флаг данжа, автосейв по утрам, обёртки save/load.
- `scripts/pause_overlay.gd` — кнопка «Сохранить», подсказка, статус-строка.
- `scripts/city.gd`, `scripts/world.gd` — пауза с сейвом вместо Esc-в-меню.
- `scripts/dungeon.gd` — транзитность (без кнопки сохранения, с пояснением).
- `scripts/main_menu.gd` — «Продолжить» грузит файл сейва.
- `loc/ru.json` — 9 новых ключей (ошибки, тосты).
- `tests/run_all.gd` — блок [M14-A]: ~45 проверок.

### Тесты (все зелёные)

- roundtrip: сетка города бит-в-бит, дорога, пень, здание, ресурсы, время,
  день, жители (настроение, пара, ссылки на здания), летопись, рюкзак,
  гримуар, монеты, навыки, HP/мана героя, день мира, зачистка данжа, туман,
  работоспособность поиска пути после загрузки;
- повторное сохранение из загруженного состояния (день продолжает расти);
- отклонение: мусор вместо JSON, чужая версия формата, отсутствие файла;
- все ключи локализации ошибок на месте.

### Приёмка (для заказчика)

1. Запустить игру, построить город, выйти на карту мира, вернуться.
2. Esc → «Сохранить игру» → «Выйти в меню» → запустить exe заново →
   «Продолжить игру» — город, мир, жители и день как были.
3. Наутро (2-й день) — тост автосохранения.
4. В данже Esc — сохранения нет, честная подсказка.

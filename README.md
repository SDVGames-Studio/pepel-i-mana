# Пепел и Мана — v1.0

Градострой + выживание + магия + рогалик в одном мире. Вы — староста (мэр)
маленького города у магической аномалии: строите город, заботитесь о жителях,
спускаетесь в данжи за рунами и кристаллами, торгуете с караванами и следите
за картой мира, где живут бандиты, торговцы и культ Пепла.

**Запуск:** `build\ПепелИМана.exe` (Windows 64-bit, установка не нужна).

## Как играть

1. **Новая игра** — выберите число жителей и запас ресурсов.
2. Ставьте здания из меню внизу: ферма даёт еду, лесопилка — дерево
   (ставьте её у деревьев!), каменоломня — камень (у скал), дома селят жителей.
3. Размечайте зоны (**Поле / Пастбище / Жилая**) — жители сами обустроят их.
   Поле сеется семенами и даёт урожай циклами; на пастбище жители приручают
   диких животных и разводят скот (молоко и яйца — в общий котёл).
4. Стройте **Яблоневый сад** (еда сама) и **Торговый двор** — тогда в город
   станут приходить караваны, а вы сможете отправлять свои (клавиша M).
5. У аномалии (фиолетовый круг) нажмите **E** — вход в данж. Там бой, лут и
   руны; из рун на алтаре крафтятся заклинания (R — панель магии).
6. С края города (западная арка) герой выходит на **карту мира**: данжи,
   руины, лагеря бандитов (внутри — бандиты-гуманоиды, будьте готовы),
   поселения фракций, караван и лагерь торговцев «гуляй-город» — телеги
   по кругу, торговля по лучшим ценам.
7. Город живёт, пока вы в данже или в пути. Волны мутантов из аномалии
   нарастают — стройте стены, вышки и держите стражей.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Ходьба (герой, везде) |
| ЛКМ | Ставить здание / рисовать дорогу / выделять зону / удар в данже |
| ПКМ / Esc | Отмена режима; Esc — пауза/меню |
| E | Взаимодействие: аномалия, вход в город, торговля, обелиск |
| Space | Рывок в данже |
| Tab | Панель жителей |
| C | Летопись (истории жителей) |
| R | Магия: крафт рун, заклинания, зачарование зданий |
| U | Дисциплины города (исследования) |
| M | Торговый двор: караваны мэра |
| 1/2/3/4 | Скорость игры x1/x2/x3/x10 |
| P | Пауза |
| F11 | Полный экран |
| Колесо мыши | Зум камеры |

## Цели

Свободной «победы» нет — играйте, как нравится: растите город, открывайте
карту мира, копите руны и заклинания, защищайте жителей. Главное — не дайте
городу умереть от голода, мутантов и магической бури.

## Подсказки

- Склад — физическое хранилище: носильщики таскают кучи ресурсов к нему.
- Дороги жители протаптывают сами; камнем можно построить вручную (быстрее).
- Зачарование зданий (R) даёт сильные бонусы, но растит магическое загрязнение.
- Лагерь бандитов силён: перед входом купите боевые комплекты в оружейной.
- Семена продаются у караванов и в лагере торговцев — без семян поля пустуют.

## 1. Общее описание

### 1.1. Питч
2D-игра с видом сверху в магическом постапокалиптическом мире: игрок строит и развивает убежище-город для выживших, управляет героем-чемпионом в процедурно генерируемых подземельях и выживает под нарастающим давлением диких магических угроз.

### 1.2. Жанр
Градостроительный симулятор + выживание + рогалик с данжен-кроулингом. Все три столпа равнозначны (решение №5): примерно треть игрового времени уходит на город, треть — на вылазки в данжи, треть — на выживание/оборону.

### 1.3. Платформа и технология
| Параметр | Значение |
|---|---|
| Движок | Godot 4.x (стабильная), GDScript |
| Графика | 2D, вид строго сверху (top-down) |
| Разрешение | 1920×1080 базовое, масштабируемое |
| Арт | пиксель-арт, тайлы и спрайты 32×32 (генерация через Blender-конвейер заказчика) |
| Платформа | Windows (exe-сборка) |
| Язык игры | русский (все тексты через таблицу локализации — задел под перевод) |
| Управление | мышь + клавиатура |
| Сохренения | локальные, автосейв + 3 ручных слота |

### 1.4. Масштаб
Большой проект. Разработка поэтапная (см. PLAN.md): **каждый этап заканчивается играбельной версией**, которую заказчик запускает и проверяет. Не переходить к следующему этапу без приёмки предыдущего.

## 2. Мир и сеттинг

- **Катаклизм:** десятилетия назад великий ритуал магов провалился — магия вырвалась на волю и пропитала всё: землю, воду, живое. (Решение №9.)
- Мир после катастрофы: руины старого мира, аномальные зоны дикого волшебства, мутировавшие существа, «дикие» заклинания, бушующие сами по себе.
- **Аномалии** — очаги чистой магии: опасны рядом, но дают ману-кристаллы. Под аномалиями лежат данжи.
- Игрок ведёт группу выживших, основавших убежище у крупной аномалии: мана — и проклятие, и главный ресурс.
- Сюжет: песочница с мягкой сюжетной рамкой (летопись поселения, случайные события-истории). Полноценная кампания — вопрос открытый (см. QUESTIONS.md п.1).

## 3. Основной игровой цикл

```
┌──────────────────────────── ЦИКЛ ИГРЫ (20–40 мин) ───────────────────────────┐
│                                                                               │
│  ГОРОД                        ДАНЖ                        ВЫЖИВАНИЕ           │
│  планируй стройку     →      снаряди героя          →    отбей атаку        │
│  назначь жителей             спускайся в подземелье      переработай добычу  │
│  управляй ресурсами          собирай лут и руны          залечи раны         │
│  ↑                           вернись (или беги)          ↑                   │
│  └───────────────────────────┴───────────────────────────┘                   │
│                    сложность растёт со временем                               │
└───────────────────────────────────────────────────────────────────────────────┘
```

1. **Город:** игрок размещает здания и зоны, назначает жителей на работы, следит за едой/безопасностью/моралью.
2. **Вылазка:** игрок лично управляет героем в процедурном данже; добыча (ресурсы, руны, артефакты) — топливо для города.
3. **Выживание:** периодические угрозы (мутанты, магические бури, осады) нарастают со временем (решение №12); город должен производить, обороняться и развиваться.

Ритм: игрок сам решает, когда идти в данж. Во время вылазки город продолжает жить (жители работают, угрозы копятся).

## 4. Системы игры

### 4.1. Город и строительство
- Строительство **свободными зонами** (решение №8): игрок выделяет мышью прямоугольную область и назначает ей тип (пастбище, поле, жилая зона) либо ставит готовые здания на свободное место. Здания строятся со временем силами жителей-строителей.
- Здания (стартовый минимум): дом, ферма, колодец, склад, мастерская, стена/частокол, сторожевая вышка, алтарь маны. Расширение списка — по этапам плана.
- Ресурсы города — общий пул (упрощение vs физический склад; пересматривается на этапе M7).
- Прогрессия города: уровни убежища открывают новые здания, дисциплины магии, лимит жителей.
- Разрушенные здания ремонтируются (ресурсы + время).

### 4.2. Жители (поселенцы)
- Жители **с личностями** (решение №11): у каждого есть имя, 2–3 черты характера, 3–5 навыков с уровнями, потребности и настроение.
- Черты влияют на поведение: «трудолюб» быстрее работает, «трус» прячется при атаке, «магофоб» портит настроение соседям-колдунам.
- Профессии (назначение игрока): строитель, фермер, носильщик, страж, маг-ученик, лекарь.
- Потребности: еда, сон, безопасность; при неудовлетворении падает мораль и производительность.
- Смерть жителя окончательна; снижает мораль поселения.

### 4.3. Выживание
- Базовые потребности поселения: **еда, вода, безопасность** (базово; тепло/сон — допущение, уточнить п.4 QUESTIONS.md).
- **Магическое загрязнение** — ключевая механика выживания: чем больше город использует магию и чем ближе к аномалиям, тем выше порча (болезни жителей, дикие события). Умеренное использование — бонусы, чрезмерное — катастрофы. (Допущение, детализация в п.2 QUESTIONS.md.)
- Угрозы **нарастающие** (решение №12): сила атак привязана к времени и уровню города; редкие крупные события (магическая буря, нашествие, странник) поверх регулярных мелких атак.

### 4.4. Герой
- **Один герой** под прямым управлением (решение №14): чемпион поселения. В городе — ходит как житель (назначения, стройка); в данже — бои и исследование.
- Характеристики: сила (урон), ловкость (скорость/уворот), воля (мана), живучесть (HP). Уровни героя дают очки навыков (простое дерево: 3 ветки по 5–7 навыков).
- Инвентарь: слоты (оружие, броня, амулет, 2 расходника) + рюкзак добычи с ограничением веса (вопрос п.5).
- **Смерть — смешанная** (решение №6): при обнулении HP герой не умирает окончательно — теряет часть добычи, выбирается из данжа тяжело раненым; лечится несколько игровых дней. Осада с провалом обороны может погубить город → конец забега или переезд (уточнить п.9 QUESTIONS.md).

### 4.5. Магия
- **Полная система** (решение №10): мана, школы, крафт заклинаний.
- Источник маны: кристаллы из данжей + алтарь в городе (допущение).
- Школы (старт): разрушение, защита, природа. Четвёртая «запретная» — с ценой (порча города) — этап M6+.
- **Крафт заклинаний:** заклинание собирается из 1–3 рун (найденных в данжах) в книге заклинаний; комбинации рун дают эффекты (руна огня + руна снаряда = огненный снаряд). Система таблицей — легко расширять контентом.
- Зачарование зданий: кристалл маны + руна = постоянный эффект здания (ферма +руна природы = +25% урожая).
- Магия визуально читаема: у каждой школы свой цвет и частицы.

### 4.6. Данжи
- **Процедурная генерация** (решение №7): комнаты+коридоры; генератор параметризован биомом, глубиной и уровнем героя.
- Структура: вход → 5–12 комнат → сокровищница/босс → выход. Глубина данжа = нарастающая сложность и ценность лута.
- Биомы (по этапам): 1) затопленные руины, 2) катакомбы, 3) кристалльные пещеры, 4) лес-мутант.
- Туман войны + автокарта. Выход в любой момент (раньше собранных сокровищ — потеря части веса при беге).
- Давление-таймер: «мана-голод» героя — держаться в данже долго опасно (допущение, уточнить п.7).
- Лут с редкостями: обычный / хороший / редкий / легендарный (таблица выпадения в данных, не в коде).
- Боссы: минимум 4 (по одному на биом), уникальная механика у каждого.
- Повторное посещение разрешено; после выноса босса данж «истощается» (меньше лута).

### 4.7. Бой
- Real-time, без пауз в данже; в городе пауза доступна всегда (допущение).
- Управление: WASD — движение, мышь — прицел/атака, 1–4 — заклинания/предметы (twin-stick, допущение — уточнить п.8).
- Механики: уворот (рывок с перезарядкой), статус-эффекты (огонь, заморозка, проклятие), ломаемое окружение.
- Враги: 12 типов на релиз MVP (по 3 на биом) + 4 босса. Дальнобойные/ближники/призыватели — ролевое разнообразие.

### 4.8. UI/UX
- Экраны: главное меню, город (основной), данж, книга заклинаний, список жителей, летопись событий, меню сохранений, настройки.
- Город и данж — два режима одной сцены-мира, переключение через вход в подземелье у аномалии.
- Обучение: контекстные подсказки первых 30 минут (допущение — уточнить п.10).
- HUD данжа: HP, мана, рывок, хотбары, миникарта, таймер мана-голода.
- HUD города: ресурсы, население/мораль, угроза (индикатор приближающейся атаки).

### 4.9. Звук
- Минимум: музыка города/данжа (2 трека, зацикленные), 10–15 базовых звуков (атака, попадание, смерть, стройка, алерт угрозы). Синтез через Blender/открытые библиотеки — детализировать на этапе M9.

## 5. Технические требования

1. Godot 4.x, проект открывается без ошибок; строгое разделение: сцены (.tscn), скрипты (.gd), данные (.json / .tres), ассеты (assets/).
2. **Данные отдельно от кода:** здания, предметы, руны, враги, заклинания, редкости — в JSON/Resource, балансировка без правки кода.
3. Генератор данжей — отдельный модуль с seed-воспроизводимостью (один seed = один данж; seed логируется для багрепортов).
4. Сейвы: JSON, версия формата, миграция при обновлении.
5. Автотесты ключевой логики (генерация данжа, экономика города, крафт рун) — headless-запуск через `godot --headless --script`.
6. Пиксель-арт конвейер: сетка символов + палитра → PNG через Blender (существующий метод заказчика); ассеты 32×32, Nearest-фильтрация.
7. Целевой FPS: 60 на среднем ПК при городе 100+ жителей и данже 60+ сущностей.
8. Структура репозитория: git, осмысленные коммиты по задачам плана.

## 7. Критерии приёмки игры (v1)
1. Забег 3+ часов: от основания убежища до победы над боссом 3-го биома.
2. Все три столпа работают и связаны: город кормит героя, данжи кормят город, угрозы требуют обоих.
3. Смерть/потери ощущаются, но не убивают прогресс города (смешанная модель).
4. Нет блокеров и крашей за 3 часа игры; сохранение/загрузка без потерь.
5. Заказчик играл и подтвердил: «понятно, интересно, хочу ещё заход».

  заказчика**.

  `CHANGELOG_E2.md`, раздел v1.26.0:

  2. **Мутанты атакуют стены**, даже когда герой стоит за ними в радиусе
     аггро (раньше залипали «иду к герою»), и **проходят через
     разрушенную стену/ворота** (пустой путь пересчитывается раз в 0.5 с).
  3. **FPS осады**: тик запертого стенами города (38 жителей + волна

     своим цветом» стало рекомендацией (самострой по-прежнему растит
     кварталы, игрок строит где хочет).
  5. Тесты: 3054 ok, новый модуль `tests/test_v126.gd`; CI зелёный.
- **Порядок работы — веточный с CI** (AGENTS.md): правка в
  `feat/<имя>` → push → CI зелёный → merge в main → удалить ветку.
- Этап 2 в режиме **правок по итогам игры**: заказчик играет и

## Как начать новый чат (первая фраза)

**Следующий шаг — ПРИЁМКА правок v1.26.0 заказчиком** (поиграть в
свежей сборке; exe пересобрать по build.bat после мержа). Дальше —
правки по итогам игры:

```
git pull, правки приёмки: <что не понравилось>
```

Агент дальше сам всё найдёт: `AGENTS.md` (процедура) → `PLAN.md` (план
и список правок) → `CHANGELOG_E2.md` (как устроено сейчас) → дизайн-доки
`docs/design/`. Агенту доступен godot-mcp (см. CHANGELOG «Инструменты»):
файловые инструменты работают сразу, редакторские — при открытом
Godot-редакторе, runtime — при запуске игры из редактора.

## Что было в правках v1.26.0 (кратко, детали в CHANGELOG_E2.md)

- **Ворота — дверь для своих**: две сетки A* (своя/мутантская), ворота
  вне коллизий героя; закрытые створки держат только волну.
- **ИИ волны**: без пути к герою мутант ломает ближайшую стену/ворота;
  пролом открывает путь (пересчёт пустого пути раз в 0.5 с); замурованный
  мутант сходит на соседнюю клетку.
- **FPS**: декор/таверна — кэш по версии зданий (сканировали все здания
  каждому жителю каждый тик), A* мутантов и погоня жителей — с
  троттлингом (`pathing` в data/city.json).
- **Районы — рекомендация**: запрета нет, кладбище — у могил.

## Обязанности агента при следующей приёмке

1. Обновить эту напоминалку (статус, версию, «что было»).
2. Отметить приёмку в `PLAN.md`, `CHANGELOG_E2.md`,
   `docs/design/ЭТАП-2-город.md` и в тексте коммита приёмки.
3. В коммите приёмки и в `PLAN.md` указать следующий шаг — чтобы новому
   чату было что найти по одной строке.
4. Пересобрать `build/ПепелИМана.exe` (build.bat) и запушить.

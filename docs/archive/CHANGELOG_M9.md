## Что нового

### Спрайты вместо примитивов (пункт 1 плана)
Единый кэш текстур `scripts/assets.gd`: ссылки на спрайты — строки
`k:<индекс>` (атлас Kenney Tiny Dungeon, 16×16, сетка 12×11), `img:<имя>`
(файл assets/sprites/), `b:<id>` (здания). Спрайты заданы в JSON-конфигах
(enemies/city/loot/dungeon), не в коде.

- **Данж**: полы и стены — тайлы Kenney, подкрашенные цветами биома
  (dungeon.json -> biomes -> floor_sprite/wall_sprite); 4 биома различаются
  и узором, и тонировкой.
- **Герой** — готический воин 32×32 (свой пиксель-арт), с фонарём и бобингом.
- **Враги (13 + 4 босса)** — каждый со спрайтом из Kenney по характеру:
  крыса/белый дух/булыжник-голем/маг-антимаг/слайм/циклоп/краб/пауки/огоньки;
  боссы — рыцарь, паук-матка, бирюзовый колосс, циклоп-тиран (крупнее, ×1.5+).
- **Жители** — по профессии (16 спрайтов), дети меньше; направление движения —
  отражением спрайта; болезнь/раны/сон — подкраской.
- **Город**: 20 зданий — сгенерированные пиксель-спрайты 32×32
  (tools/make_buildings.py, Blender headless: фахверк, крыши, трубы, зубцы,
  вывески, горны); деревья, скалы, рудная жила; кучи ресурсов у зданий —
  спрайтом главного ресурса, размер растёт с количеством.
- **Карта мира**: точки интереса — спрайты (город-домик, аномалия-алтарь,
  руины-портал, лагерь-бандит, поселение-житель, караван-путник,
  обелиск-статуя); павшие поселения серые с чёрным крестом; герой — воин
  с бобингом и тенью.
- **Дешёвые анимации (по плану)**: бобинг (ходьба/дыхание), отражение по
  направлению, вспышка урона (спрайт светлеет через modulate, без
  перерисовки), пульс-подсветка у аномалии/выхода/точек интереса.
- Лут: мана — синее зелье-кристалл, предметы и руны — по таблице из loot.json
  (мечи, кинжалы, свечи-руны, сундуки с камнем).
- Ассеты: `assets/sprites/kenney.png` (атлас среды), `kenney_sprites.png`
  (существа/предметы с вырезанным тёмным фоном — tools/prepare_atlas.py),
  `knight.png`, `buildings/*.png` (20), tree/rock/ore, `icon.png` (иконка
  игры 128×128 из воина). Контрольные листы индексов — tools/spritemap.png,
  tools/tilepick.png, tools/buildings_sheet.png.

### Оптимизация (пункт «60 FPS»)
- Статический слой города `scripts/city_terrain.gd`: ландшафт (~2800 тайлов)
  рисуется один раз, а не каждый кадр; динамика — в city_view как раньше.
- Враги данжа не перерисовываются каждый кадр: перерисовка только по событиям
  (урон/стан/замедление/смена HP), вспышка урона живёт в modulate спрайта.
- Кэш текстур в assets.gd: атлас и спрайты загружаются один раз.

### Платформенные мелочи
- Иконка игры (icon.png) подключена в project.godot.
- Полноэкранный режим: **F11** из любой сцены + галочка в главном меню;
  выбор запоминается (user://settings.cfg).
- Пауза в данже по **Esc** (`scripts/pause_overlay.gd`): вуаль + «Продолжить»
  / «Выйти в меню». Пауза города была (P/кнопка).
- Звук и обучение — не делались (решение заказчика 2026-10-17).

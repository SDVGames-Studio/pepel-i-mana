# Архив этапов M0–M14

Здесь лежат закрытые поэтапные журналы `CHANGELOG_M*.md` — что делалось
на этапах M0–M14 (2026-10-13 … 2026-10-21) и как принималось. Этапы
давно закрыты и приняты заказчиком (итоги — в `PLAN.md`), поэтому журналы
убраны из корня, чтобы не мешать.

**Актуальный журнал — `CHANGELOG_E2.md` в корне** (Этап 2 «Полировка
города», версии v1.x). Новые записи пишутся только туда.

Править эти файлы не нужно — только читать, если нужен исторический
контекст по ранней реализации системы.

# CHANGELOG M2 — Город-минимум

**Версия 0.3.0 (2026-10-13). Цель этапа:** playable город, столп «градострой» в минимальном виде.

## Что появилось

### Карта города
- Тайловая карта 44×30 (генерация по seed, детерминированная): трава, озёра, скалы, деревья.
- Аномалия у правого края — вход в данж (E рядом с ней). Проверка связности: от старта до аномалии всегда дойти можно.
- Жители ходят по AStarGrid2D (без диагоналей), герой — WASD с коллизиями (вода, скалы, готовые здания).

### Стройка (ответ №16 — достраивают рабочие)
- 9 типов зданий: 8 из ТЗ 4.1 (дом, ферма, колодец, склад, мастерская, частокол, сторожевая вышка, алтарь маны) + лесопилка (нужна для цепочки «лесопилка→дерево» из плана M2).
- Игрок выбирает здание на нижней панели, ставит ЛКМ (призрак: зелёный — можно, красный — нельзя), ПКМ/Esc — отмена. Ресурсы списываются сразу, площадку достраивает строитель (таймер работы).
- Строить нельзя: на воде/скалах, на занятом тайле, на аномалии.
- Эффекты: дом +2 к лимиту жителей и быстрый сон; колодец ускоряет отдых; склад +200 к вместимости; частокол — преграда; вышка — пост стража; алтарь (2 кристалла маны) с магом-учеником даёт +10% производству.

### Ресурсы — общий пул (по плану M2; ответ №20 «физическое хранение» — пересмотр на M7)
- Дерево, камень, еда, кристаллы маны. Вместимость: базово 150, склады расширяют. Все цифры в `data/city.json`.

### Жители-статисты (без личностей — личности в M4)
- Старт: 5 жителей + герой (ответ №11), число и запас ресурсов настраиваются в меню до старта.
- 6 профессий (ТЗ 4.2 + ответ №32): строитель, фермер, лесоруб, мастер, страж, маг-ученик. Автоназначение на свободные рабочие места.
- Еда: каждый житель ест 2/день; пусто — голод, работа стоит. Сон: ночью все идут в дома (быстрое восстановление), без дома спят где стоят; страж ночью на вышке. Уставшие отдыхают днём.

### Производственные цепочки
- ферма → еда (фермер), лесопилка → дерево (лесоруб), мастерская → камень (мастер). Благословение алтаря ускоряет всё производство.

### Город ↔ данж
- Выход из данжа (E на лестнице) возвращает в город; добыча (каменная крошка, кристаллы эха) падает в пул города, руны остаются в рюкзаке (пригодятся в M3).
- Город живёт, пока герой в данже (сим тикается в автозагрузке Game).

### Пауза и скорость
- P — пауза, клавиши 1/2/3 — скорость x1/x2/x3 (кнопки на HUD тоже). Из паузы любую скорость снимает паузу.

## Управление в городе
| Клавиша | Действие |
|---|---|
| WASD | ходить героем |
| ЛКМ | поставить здание (в режиме стройки) |
| 1–9 клики по панели | выбрать здание |
| E | войти в аномалию (данж) |
| P / 1 / 2 / 3 | пауза / скорость |
| Tab | список жителей |
| Esc | отмена стройки → список жителей → меню |

## Приёмка (цикл замкнут)
Город производит еду/дерево/камень → герой ходит в данж и приносит кристаллы и камень → кристаллы идут в алтарь (+10% производству), камень и дерево — в новые здания → город растёт (склады, дома, вышки).

## Границы этапа (сознательно за рамками M2)
- Деревья на карте пока декорация; лесопилка добывает дерево абстрактно.
- Смерть от голода (ответ №44) — не реализована: при нуле еды жители просто не работают. Придёт с выживанием (M5).
- Ручное назначение профессий, дороги, зоны, ремонт разрушений — M4/M6.
- Пиксель-арт зданий/жителей — M8 (сейчас цветные примитивы).

## Техническое
- Логика без сцены: `city_map.gd` (ландшафт+AStar), `city_sim.gd` (экономика, жители) — покрываются headless-тестами. Сим живёт в автозагрузке `Game`, город тикается и во время вылазки.
- Автотесты: 224 проверки (было 79) — `test.bat`. Дымовые прогоны сцен city/menu/dungeon headless — без ошибок.
- Грабли GDScript 4 (в копилку): прямой доступ `_def(b)["effect"]` роняет парс/рантайм, если ключ есть не у всех вариантов (у фермы нет effect) — только `.get(key, default)`; вывод типа `:=` от атрибутов нетипизированных объектов (`map.tile_of_px()`) запрещён — писать явные типы.

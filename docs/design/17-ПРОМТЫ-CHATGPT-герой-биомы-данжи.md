# Промты для ChatGPT: герой, биомы, подземелья (v1.75.9)

> Готовые к копированию промты. Основано на принятом конвейере:
> лист → папка «новые ассеты» → слайсер агента → игра.
> Общие правила формата — в docs/design/16-АССЕТЫ-ТЗ.md.

## ГЛАВНОЕ ПРАВИЛО ФОРМАТА (вставлять в каждый промт)

```
ФОРМАТ ЖЁСТКИЙ:
- PNG с ПРОЗРАЧНЫМ фоном (или однотонный ярко-пурпурный #FF00FF — но НЕ
  белый, НЕ чёрный, НЕ серый, НЕ шахматная «прозрачность» — она запекается
  в картинку и портит нарезку)
- размер листа 1254×1254 или 1536×1024
- БЕЗ текста, подписей, рамок и номеров на листе
- объекты не касаются друг друга и краёв листа (зазор от 20 px)
- единый масштаб и единая высота персонажа во всех кадрах листа
```

## ШАГ 0 — СТИЛЬ-ЛИСТ (первый промт нового диалога, БЕЗ референсов)

Референсы не нужны: первым же промтом попроси ChatGPT нарисовать
МАЛЕНЬКИЙ эталонный лист. Ты его принимаешь (или просишь поправить),
и он становится образцом стиля: каждый следующий промт в этом диалоге
начинается словами «в точности стиль стиль-листа выше».

```
Нарисуй СТИЛЬ-ЛИСТ пиксель-арт игры «Пепел и Мана» — эталон стиля для
всех следующих листов. На одном листе 1254×1254, прозрачный фон:
1) рыцарь в тёмной броне с алым плащом и мечом, вид сбоку, полный рост
   (~100 px), стоя
2) крестьянский дом-изба: сруб, двускатная драночная крыша, резные
   наличники, тёплое окно, вид сверху ¾ (~120 px)
3) ель тёмно-зелёная (~64 px)
4) плита пола подземелья 32×32 (серый камень, трещины)
5) пурпурный кристалл маны (~32 px)

СТИЛЬ ЖЁСТКИЙ:
- пиксель-арт, тёмное славянское фэнтези, вид сверху ¾
- палитра приглушённая землистая: тёмное коричневое дерево, серый камень,
  болотный мох, серо-чёрный пепел; тёплые янтарные акценты (огонь, окна,
  свечи); пурпур — ТОЛЬКО магия Пепла. БЕЗ кислотных цветов, БЕЗ чистого
  белого, БЕЗ градиентов и фототекстур
- обводка темнее заливки (1 px в масштабе), чистый читаемый силуэт
- славянские мотивы: резьба, обереги, лемех-крыши, рушники
- тени мягкие, земля тёплая тёмная
```

Принял стиль-лист → дальше во ВСЕХ промтах этого диалога первая фраза:
«В ТОЧНОСТИ стиль стиль-листа выше (палитра, обводка, пропорции)».

## ПРОМТ 1 — ГЕРОЙ: полный лист движений (заменяет «куцые» ряды)

```
Нарисуй спрайт-атлас пиксель-арт ГЛАВНОГО ГЕРОЯ «Пепел и Мана»:
мрачный рыцарь с алым плащом и мечом — ТОТ ЖЕ персонаж, что на
СТИЛЬ-ЛИСТЕ выше (та же броня, тот же силуэт и палитра).

ЛИСТ: PNG, прозрачный фон, 1536×1024. Сетка: 12 колонок × 8 рядов,
кадр ~128×118 px, между рядами пустая полоса 10+ px. Герой ОДНОГО роста
во всех кадрах (~100 px), ноги на одной базовой линии, персонаж всегда
целиком в кадре, ничего не обрезано. Персонаж смотрит ВПРАВО (зеркалить
будет движок). В каждом кадре — только герой (без эффектов фона; магия —
пурпурное свечение у кисти/клинка, не заливающее кадр).

РЯДЫ (сверху вниз, слева направо, пустые клетки в конце ряда оставить
пустыми):
1) СТОЙКА-ДЫХАНИЕ — 10 кадров: лёгкий вдох-выдох, покачивание плаща,
   НЕ меняет позу radically (это цикл дыхания, не разные позы)
2) БЕГ ВБОК (профиль вправо) — 10 кадров: полный цикл шага, развевающийся
   плащ, 2-3 кадра «в воздухе» между шагами
3) БЕГ ВВЕРХ (СПИНОЙ к зрителю, вид сзади) — 10 кадров того же бега
4) БЕГ ВНИЗ (АНФАС) — 10 кадров того же бега
5) АТАКА МЕЧОМ — 9 кадров = 3 удара по 3 кадра (замах → удар с
   траекторией клинка → финиш-позиция с мечом вниз). Удары разные:
   горизонтальный, вертикальный, колющий
6) КАСТ МАГИИ — 8 кадров: подъём руки, пурпурное свечение нарастает,
   выброс заклинания, возврат
7) РЫВОК/КУВЫРОК — 8 кадров: группировка, перекат через плечо вправо,
   выход в стойку
8) ПОЛУЧЕННЫЙ УРОН + СМЕРТЬ — 12 кадров: первые 3 — отшатывание от
   удара (кадры урона), затем падение на колено, падение ничком,
   растворение в пепле (5-7 кадров смерти)
```

Дополнительно (по желанию, отдельным листом 1536×1024, тем же промтом):
```
РЯД КРАДУЧИСЬ: 10 кадров подкрадывания в полуприседе с мечом наготове
(вид вправо), осторожные короткие шаги.
РЯД С ЩИТОМ: блок стоя/бег с щитом.
```

## Если стиль в диалоге «уплывает»

Скопируй стиль-лист из диалога и прикрепи его обратно файлом к промту:
«вот эталон, рисуй в точности так». Для этого в репо есть готовые
принятые листы (папка F:\востановление кхорно юнитовssets\ассеты
домов\референсы\ — РЕФЕРАЕНС-герой-рыцарь, РЕФЕРЕНС-жители,
РЕФЕРЕНС-монстры).

## Куда класть готовое

```
F:\востановление кхорно юнитов\assets\ассеты домов\новые ассеты\
```
(для героя — подпапка «главный герой»; для тайлов — новая подпапка
«биомы» / «данжи»). После этого написать агенту фразу из
СЛЕДУЮЩИЙ-ШАГ.md («ассеты готовы, нарежь»).

## Чек-лист приёмки листа (проверяет агент)

1. Фон прозрачный или #FF00FF; шахматка/белый/чёрный = перекрасить.
2. Нет текста/рамок; объекты не касаются краёв и друг друга.
3. Один рост персонажа / один масштаб внутри листа.
4. Ряды разделены пустыми полосами; кадры не слиплись.
5. Герой смотрит вправо; ноги на одной линии.
6. Стиль совпадает со стиль-листом диалога (палитра/обводка/пропорции).

## v1.79 — НОВЫЙ ПОДХОД: «ОДНО ПОЛОТНО» вместо маленьких кусков

Почему: нарезка тайлов из ИЛЛЮСТРАЦИЙ (лес-сцена с деревьями, цветами,
камнями) даёт «мессиво» — каждый тайл со своей картинкой, стилистика
гуляет, земля не сливается. Решение: биом = ОДНО БОЛЬШОЕ БЕСШОВНОЕ
ПОЛОТНО земли. Слайсер агента сам нарежет его на 32×32 — все тайлы
гарантированно из одной картинки: один тон, одна фактура, швов нет.

### ПРОМТ «ПОЛОТНО БИОМА» (один биом = один промт)

```
В ТОЧНОСТИ стиль стиль-листа выше (палитра, обводка, пропорции).

Нарисуй БЕСШОВНУЮ ТЕКСТУРУ ЗЕМЛИ биома «ЛЕТО» — одно цельное
полотно-текстуру, НЕ тайл-сет, НЕ мозаика из квадратиков.

ФОРМАТ ЖЁСТКИЙ:
- 1024×1024, вид сверху (чуть ¾), пиксель-арт
- КРАЯ СШИВАЮТСЯ: левый край стыкуется с правым, верхний с нижним
  (текстура ЗАМОЩАЕТСЯ бесшовно — seamless tileable texture)
- БЕЗ деревьев, кустов, камней, цветов-объектов, БЕЗ объектов вообще —
  ТОЛЬКО поверхность земли
- равномерная плотность фактуры в каждом месте (не «пятна пустоты» и
  не «пятна деталей»)

СОДЕРЖИМОЕ (лето): луговая трава — приглушённая землистая зелень,
мелкая трава в пикселях, редкие травинки и мелкие цветочные крапинки
в ТОНе травы (не яркие пятна). Всё в одной плотности по всему полю.

СТИЛЬ: тёмное славянское фэнтези, приглушённая палитра, тёплая тёмная
земля, БЕЗ чистого белого, БЕЗ градиентов.
```

(для каждого биома заменить последний блок: «осень» — опавшая листва
бурая с редкими листьями; «зима» — снег с лёгкой тенью сугробов;
«болота» — мокрая тина и кочки БЕЗ воды; «пустыня» — песок с ветряной
рябью; «степи» — сухая жёлтая трава; «скалы» — каменистая осыпь;
«мёртвый лес» — серый пепел и голая земля; «огненные земли» —
обожжённая порода с углями в тоне; «цветущий край» — луг с мелкими
цветами В ТОНе; «проклятый лес» — тёмная фиолетово-зелёная глушь).

Затем ОДИН отдельный промт на объекты этого биома:

```
В ТОЧНОСТИ стиль стиль-листа выше. Нарисуй лист ОБЪЕКТОВ биома «ЛЕТО»:
8-10 деревьев этого биома (разные, 64-96 px, вид чуть ¾, у корня
плотная тень-эллипс НЕ включать), плюс 3-4 куста/камня/пня 32-48 px.
Прозрачный фон 1536×1024, объекты не касаются краёв и друг друга,
единый масштаб. ДЕРЕВЬЯ СТОЯТ НА ЗЕМЛЕ ПОЛОТНА (ножки на уровне низа).
```

Конвейер: полотно → tools/slice_field.py (автонож: полотно в 24+
тайла 32×32 с общим тоном — гарантированное единообразие) →
композитор/город как обычно.

### ПРОМТ «ГЕРОЙ: один лист, один рост» (замена смеси стилей)

Проблема: листы героя из разных диалогов ИИ = разный рыцарь (тёмный /
красный плащ / разный рост) → «при разных айдалах бежит в разные
стороны и разного размера». Решение: ВСЕ анимации ОДНИМ промтом
одного диалога, с жёстким якорем персонажа.

```
В ТОЧНОСТИ стиль стиль-листа выше. Нарисуй ПОЛНЫЙ АТЛАС ГЕРОЯ —
мрачный рыцарь в алой накидке и стальной кирасе с мечом.
ОДИН И ТОТ ЖЕ рыцарь во всех кадрах: одна броня, один плащ, один
меч, один рост (высота фигуры 96 px в каждом кадре, стоит на одной
линии земли — низ кадра).

Лист 1536×1024, прозрачный фон, КАЖДЫЙ РЯД — своя анимация, кадры
в ряд с равными промежутками, СМОТРЯТ ВПРАВО:
РЯД 1 (6 кадров): стойка-дыхание, меч опущен
РЯД 2 (6 кадров): бег в профиль вправо
РЯД 3 (6 кадров): бег СПИНОЙ к зрителю (вверх)
РЯД 4 (6 кадров): удар мечом — замах, дуга, завершение
РЯД 5 (6 кадров): рывок-перекат
РЯД 6 (6 кадров): каст — рука к небу, алые искры
РЯД 7 (6 кадров): падение назад и лежит
БЕЗ текста и рамок. Кадры не касаются краёв и друг друга.
```

## v1.79.3 — МАСТЕР-ПРОМТ «ЗЕМЛЯ БИОМА» (копировать целиком в новый чат)

Проверенный формат под нарезку на 32×32. Генерируй 4 раза — по одному
на сезон, меняя только блок «СОДЕРЖИМОЕ». Готовый файл назови
«полотно-весна.png» и т.д. и положи в папку «новые ассеты монстров» —
скажи агенту «полотна готовы», он нарежет и подключит.

```
Нарисуй ОДНУ бесшовную текстуру пиксель-арт земли для игры вида сверху.

ЧТО ЭТО: цельное полотно-текстура 1024×1024, которое замощается
бесшовно (левый край переходит в правый, верхний — в нижний). Это НЕ
мозаика из квадратиков, НЕ тайл-сет, НЕ карта — просто равномерная
ткань земли.

ВИД: строгий пиксель-арт сверху (вид почти вертикально вниз, лёгкий
наклон ¾ допустим), крупные читаемые пиксели, БЕЗ сглаживания, БЕЗ
градиентов, БЕЗ размытия.

СОДЕРЖИМОЕ (ВЕСНА): влажная тёмно-зелёная луговая земля ранней весны.
Мелкая трава в 3-4 близких оттенка зелёного, редкие тонкие травинки,
изредка одиночные мелкие белые цветочки размером 2-3 пикселя, чуть
темноватые проплешины влажной земли. ВСЁ в одной приглушённой гамме.

ЖЁСТКИЕ ПРАВИЛА (нарушение = брак):
1. БЕСШОВНОСТЬ: края полотна сшиваются идеально, никаких видимых
   границ, полос или швов.
2. РАВНОМЕРНОСТЬ: плотность деталей ОДИНАКОВА во всех участках —
   никаких «пустых пятен» и «густых пятен», никаких крупных объектов.
3. СПОКОЙНАЯ ГАММА: все цвета близки друг к другу (разброс яркости
   небольшой), БЕЗ ярких кислотных пятен, БЕЗ чистого белого и чёрного.
4. ПИКСЕЛЬ-АРТ: чёткие пиксельные ступеньки, видимые пиксели, стиль
   SNES-эпохи, никакого фотореализма и живописных мазков.
5. БЕЗ ОБЪЕКТОВ: никаких деревьев, кустов, камней, построек, персонажей,
   теней от них — ТОЛЬКО поверхность земли.
6. БЕЗ ТЕКСТА, подписей, рамок, водяных знаков.

ПАЛИТРА (держись её): тёмная землистая — болотный мох, тёмная зелень,
тёплая коричневая земля, серый камень; тёплые янтарные акценты только
в мелких деталях. Тёмное славянское фэнтези.
```

### Сезонные замены блока «СОДЕРЖИМОЕ»:

- ЛЕТО: сочная тёмно-зелёная луговая трава, травинки, редкие жёлтые
  цветочки мелко, чуть выгоревшие проплешины.
- ОСЕНЬ: бурая и рыжая опавшая листва на тёмной влажной земле,
  редкие жёлто-красные листья мелко, голая тёмная земля проплешинами.
- ЗИМА: серо-белый снег с лёгкой голубизной теней сугробов, редкие
  тёмные травинки сквозь снег, никаких ярких пятен.
- БОЛОТА: мокрая тёмно-зелёная тина, кочки, лужи тинистой воды без
  бликов, камыши НЕ рисовать (объекты отдельно).
- ПУСТЫНЯ: жёлто-песчаный песок с ветряной рябией, редкие камешки.

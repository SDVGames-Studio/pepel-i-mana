# Промты для ChatGPT: герой, биомы, подземелья (v1.75.9)

> Готовые к копированию промты. Основано на принятом конвейере:
> лист → папка «новые ассеты» → слайсер агента → игра.
> Общие правила формата — в docs/design/16-АССЕТЫ-ТЗ.md.

## ГЛАВНОЕ ПРАВИЛО ФОРМАТА (вставлять в каждый промт)

```
ФОРМАТ ЖЁСТКИЙ:
- PNG с ПРОЗРАЧНЫМ фоном (или однотонный ярко-пурпурный #FF00FF — но НЕ
  белый, НЕ чёрный, НЕ серый, НЕ шахматная «прозрачность» — она запекается
  в картинку и портит нарезку)
- размер листа 1254×1254 или 1536×1024
- БЕЗ текста, подписей, рамок и номеров на листе
- объекты не касаются друг друга и краёв листа (зазор от 20 px)
- единый масштаб и единая высота персонажа во всех кадрах листа
```

## СТИЛЬ-ЯКОРЬ (вставлять в каждый промт + ПРИЛОЖИТЬ принятый атлас)

```
Стиль: пиксель-арт, тёмное славянское фэнтези («Пепел и Мана»). Прилагаю
принятый атлас — рисуй В ТОЧНОСТИ в его стиле, палитре и толщине обводки.
Палитра: приглушённые землистые (тёмное дерево, серый камень, мох, пепел),
тёплые янтарные акценты (огонь, окна), пурпур — только магия Пепла.
Чистый читаемый силуэт, обводка темнее заливки, без фототекстур и
градиентов. Славянские мотивы: резьба, обереги, лемех, кайма рушников.
```

## ПРОМТ 1 — ГЕРОЙ: полный лист движений (заменяет «куцые» ряды)

```
Нарисуй спрайт-атлас пиксель-арт ГЛАВНОГО ГЕРОЯ для игры «Пепел и Мана»
(тёмное славянское фэнтези): мрачный рыцарь с алым плащом и мечом —
ТОЧНО тот же персонаж, что на приложенном референсе (приложи прошлый
атлас рыцаря), та же броня, тот же силуэт и палитра.

ЛИСТ: PNG, прозрачный фон, 1536×1024. Сетка: 12 колонок × 8 рядов,
кадр ~128×118 px, между рядами пустая полоса 10+ px. Герой ОДНОГО роста
во всех кадрах (~100 px), ноги на одной базовой линии, персонаж всегда
целиком в кадре, ничего не обрезано. Персонаж смотрит ВПРАВО (зеркалить
будет движок). В каждом кадре — только герой (без эффектов фона; магия —
пурпурное свечение у кисти/клинка, не заливающее кадр).

РЯДЫ (сверху вниз, слева направо, пустые клетки в конце ряда оставить
пустыми):
1) СТОЙКА-ДЫХАНИЕ — 10 кадров: лёгкий вдох-выдох, покачивание плаща,
   НЕ меняет позу radically (это цикл дыхания, не разные позы)
2) БЕГ ВБОК (профиль вправо) — 10 кадров: полный цикл шага, развевающийся
   плащ, 2-3 кадра «в воздухе» между шагами
3) БЕГ ВВЕРХ (СПИНОЙ к зрителю, вид сзади) — 10 кадров того же бега
4) БЕГ ВНИЗ (АНФАС) — 10 кадров того же бега
5) АТАКА МЕЧОМ — 9 кадров = 3 удара по 3 кадра (замах → удар с
   траекторией клинка → финиш-позиция с мечом вниз). Удары разные:
   горизонтальный, вертикальный, колющий
6) КАСТ МАГИИ — 8 кадров: подъём руки, пурпурное свечение нарастает,
   выброс заклинания, возврат
7) РЫВОК/КУВЫРОК — 8 кадров: группировка, перекат через плечо вправо,
   выход в стойку
8) ПОЛУЧЕННЫЙ УРОН + СМЕРТЬ — 12 кадров: первые 3 — отшатывание от
   удара (кадры урона), затем падение на колено, падение ничком,
   растворение в пепле (5-7 кадров смерти)
```

Дополнительно (по желанию, отдельным листом 1536×1024, тем же промтом):
```
РЯД КРАДУЧИСЬ: 10 кадров подкрадывания в полуприседе с мечом наготове
(вид вправо), осторожные короткие шаги.
РЯД С ЩИТОМ: блок стоя/бег с щитом.
```

## ПРОМТ 2 — БИОМЫ: тайлы 32×32

```
Нарисуй тайл-атлас биомов для пиксель-арт игры «Пепел и Мана» (тёмное
славянское фэнтези; стиль — в точности как на приложенном референсе).
PNG, прозрачный фон, 1536×1024. Группы по 4 ВАРИАЦИИ каждого тайла,
тайлы 32×32, КАЖДЫЙ тайл бесшовно стыкуется сам с собой по всем краям
(без швов и стыков). Внутри группы тайлы похожи, но не идентичны.

ГРУППЫ (рядами, слева направо):
- трава леса, трава лугов, степь, болото (с лужами), пепел/выжженная
  земля с тлеющими трещинами, проклятый лес (чёрная кора, красные жилы),
  зимний снег, пустынный песок, горная скала
- вода: река горизонталь, река вертикаль, изгиб русла, озеро, мелководье
- берега (обрывы земли к воде): север, юг, запад, восток, углы внутрь и
  наружу, брод (мелкая вода с камнями)

ДЕКОР отдельным блоком НИЖЕ (каждый объект целиком, зазор 20+ px,
не касаются краёв): ель, берёза, сухое дерево, красное дерево (осень),
проклятое дерево; пень, камень малый/большой, куст, цветы полевые,
грибы, кости/череп, дорожный крест, языческий идол, придорожный флаг.
Деревья ~48-64 px высотой, низ дерева — «пень» 32×32 для стыковки с полом.
```

## ПРОМТ 3 — ПОДЗЕМЕЛЬЯ: тайл-сеты данжей

```
Нарисуй тайл-атлас ПОДЗЕМЕЛИЙ для пиксель-арт игры «Пепел и Мана»
(тёмное славянское фэнтези, вид сверху ¾; стиль — как на приложенном
референсе полов/стен данжа). PNG, прозрачный фон, 1536×1024.
Тайлы 32×32, полы и стены бесшовны.

ДЛЯ КАЖДОГО ИЗ 4 БИОМОВ ДАНЖА (рядами):
КАТАКОМБЫ (серый камень, плиты, трещины), КРИПТА НЕЖИТИ (черепа в стенах,
синеватый мох), ПЕЩЕРЫ МУТАНТОВ (сырой камень, сталактиты, пепел),
ЛАВА/ПЕПЕЛЬНОЕ ЛОГОВО (обожжённый камень, тлеющие трещины):

- пол: 4 вариации плиты
- стены: прямая горизонталь, прямая вертикаль, угол, Т-стык, крест,
  торец (вид сверху ¾: стена высотой ~48 px с «лицом» кладки и верхней
  кромкой)
- внутренние углы и внешние углы стен
- дверь арочная каменная (в проёме 2×1 тайла), дверь-решётка
- декор: бочка, черепа кучей, могильная плита, саркофаг, кристалл маны
  (пурпурный), жаровня с огнём, паутина, щебень
```

## Чек-лист приёмки листа (проверяет агент)

1. Фон прозрачный или #FF00FF; шахматка/белый/чёрный = перекрасить.
2. Нет текста/рамок; объекты не касаются краёв и друг друга.
3. Один рост персонажа / один масштаб внутри листа.
4. Ряды разделены пустыми полосами; кадры не слиплись.
5. Герой смотрит вправо; ноги на одной линии.
6. Приложить прошлый принятый лист как референс («тот же стиль»).

## 1. БИОМЫ

### 1.1 Что уже работает (большая часть сделана раньше запрета)

- **Сезонная земля города** (v1.76–1.79): лето — обычная dual-grid трава,
  весна = МОХ (полотно заказчика), осень и зима — свои полотна; смена
  сезона перезагружает землю. Тег биома: `Assets.biome_tag_for_season()`
  (city_terrain_base); пиксель земли 1:1 (v1.79.11, отмена апскейла).
- **Полотна и нарезка — В РЕПЕ**: `assets/sprites/env/biomes/` — исходные
  «полотно-атлас.png» (4-в-1) и «полотно-сезоны.png» + тайлы 32×32 и
  manifest.json. В манифесте **16 биомов**: весна, лето, осень, зима
  (сезонные) + болота, мох, пустыня, степи, скалы, мёртвый лес, древний
  лес, мистический лес, проклятый лес, огненные земли, берёзовая роща,
  цветущий край (тематические). Пропавшие исходники заказчика не нужны —
  всё нарезано и закоммичено.
- **Композитор-рисовалка в игре** (v1.78.8, кнопка в меню): заказчик
  рисует каждый тайл сам кистью по холсту 20×20 (вкладки биомов, у каждой
  своё сохранение; тайл из библиотеки = кисть; ПКМ — ластик; вода — полоса
  листа с перекраской берега). Сохранение в `user://biomes_composed/
  <имя>/biome.json` — город рисует ровно этот рисунок, тайлясь по миру,
  без переимпорта и работает в экспорте.
- **Галерея биомов на стенде** (v1.76.3): патч 20×20 на каждый биом
  манифеста — все биомы одним взглядом; `SHOT_BIOME=<тег>` — превью
  любого биома в городе.
- **Деревья**: пулы города — wave-деревья + пакет B (`tree3_*`, 16
  стволов с сезонными линиями и кластерами-«урочищами», v2.4.0/2.4.1).

## 3. VIEW-СЛОЙ ГЛУБОКИЙ (тех-долг запечки)

### 3.1 Как устроен рендер города

- **Запечка** (city_terrain.gd): земля в текстуру ландшафта — зоны,
  дороги, плиты площади, декор луга, поля (заливки/борозды/заборы),
  полотно биома (`_biome_canvas`, grid 20×20). Rebake по версии сетки;
  «rebake(true) при неизменившейся сетке пропускал перекраску» — старый
  глюк, вылечен (v1.59).
- **Живой слой** (city_view_base + nature/props): LOD по зуму —
  травинки/блики только при zoom ≥ 1.5, шаг прореживания 2/4 (v1.50/1.52);
  вода vis-first, вне кадра не перекрашивается (bbox один раз), кап
  анимации воды 15→10 (v2.4.1: старт 9→17 FPS, разогрев 42–65;
  диагностика tools/diag_layers.gd: вода ела ~40 FPS — закрыто).
- **Капы v1.80.7**: view 30fps, полотно ≤48 квадов, вода vis-first,
  свет 14 источников.

### 3.2 Что значит «запечка глубже» и чего стоит

- **Смысл**: перенести в текстуру ландшафта ещё статичное из живого слоя
  (пни, брёвна, камни, идолы — всё без анимации) и/или уйти на MultiMesh
  для квадов деревьев. Выигрыш — FPS на слабом железе.
- **Цена/риск**: инвалидация запечки при каждой стройке/сезоне/плесени;
  регрессии сортировки (дерево перед/за домом) и света; данж и карта
  мира — отдельные слои, их это не касается.

### 3.3 План (делать только по приказу — триггер «если ФПС опять просят»)

1. **Замер**: diag_layers.gd на 2.7.1 — что реально ест FPS сейчас
   (после капов 2.4.1 вода уже не главный кандидат; лидер неизвестен).
2. **По результатам**: запечь статику (пни/брёвна/камни) в ландшафт по
   чанкам с инвалидацией по версии сетки; MultiMesh — только если замер

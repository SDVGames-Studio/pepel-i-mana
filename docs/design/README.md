# Дизайн-документы по модулям («дизайн-библия»)

Каждый файл здесь — **один модуль игры**: что в нём есть, как он работает,
что уже реализовано и что планируется. Это прослойка между документами
проекта и кодом:

- `TZ.md` — что это за игра (не меняется задним числом);
- `docs/design/*.md` — **как устроена каждая система и какой мы хотим её видеть**;
- `data/*.json`, `scripts/*.gd` — реализация.

## Зачем это нужно

Чтобы любую задачу можно было ставить одной фразой: «работаем по модулю
`05-загрязнение`, реализуй пункт такой-то из раздела 6» — и ИИ-агент (или
новый человек) читал один файл вместо всего проекта.

## Как пользоваться заказчику

1. Хотите что-то добавить или поменять — откройте файл модуля, опишите
   идею в разделе **«6. Хочу добавить / изменить»** (одна строка = одна идея).
2. Поставьте ИИ задачу, например:
   «Возьми идею №2 из `docs/design/05-загрязнение.md`, спроектируй и реализуй».
3. После приёмки идея переносится в `PLAN.md` и реализуется по обычной
   процедуре из `AGENTS.md`.

## Правила для ИИ-агента

1. **Перед задачей по системе** прочитай её файл целиком, плюс `TZ.md §4`
   и пункты `QUESTIONS.md`, на которые он ссылается.
2. **Правил механику или баланс — обнови файл модуля** в том же коммите
   (разделы 3 и 5). Документ отстаёт от кода = документа нет.
3. **Новая идея заказчика** сначала фиксируется в разделе 6 файла модуля,
   потом становится задачей в `PLAN.md`. Не реализовывать то, чего нет
   в разделе 6 или в задаче.
4. **Числа баланса живут в `data/*.json`** — в дизайн-доке только принципы
   и выжимка-таблица со ссылкой на конфиг.
5. **Связи между модулями держи двусторонними**: если в модуле А появилась
   зависимость от Б, у Б в разделе 4 должна появиться ссылка на А.
6. **Новый модуль** — копией `_ШАБЛОН.md`, номер продолжает нумерацию;
   после создания добавь строку в карту модулей ниже.
7. **Раздел 8 каждого модуля — вопросы заказчику.** Заказчик отвечает
   (правкой файла или списком в чате), агент вливает ответы в разделы 3
   и 6, после чего отвеченные вопросы удаляет. Не реализовывать механику,
   пока вопрос по ней не отвечен.

## Как модули связаны (грубая карта)

```
06-МИР ──угрозы/POI──► 09-УГРОЗЫ ──атаки──► 01-ГОРОД ──оборона──► 09-УГРОЗЫ
01-ГОРОД ──жители──► 02-ЖИТЕЛИ ──труд──► 03-ЭКОНОМИКА ──ресурсы──► 01-ГОРОД
04-МАГИЯ ──зачарования/запретная школа──► 05-ЗАГРЯЗНЕНИЕ ──порча──► 01/02/10
07-ПОДЗЕМЕЛЬЯ ──руны/кристаллы/лут──► 04-МАГИЯ / 03-ЭКОНОМИКА
08-ГЕРОЙ ──связывает──► 01-ГОРОД, 07-ПОДЗЕМЕЛЬЯ, 09-УГРОЗЫ, 06-МИР
10-ПРИРОДА ──гнев леса──► 09-УГРОЗЫ; 05-ЗАГРЯЗНЕНИЕ ──порча──► 10-ПРИРОДА
11-СЮЖЕТ / 12-УПРАВЛЕНИЕ ──поверх всех──► модифицируют правила 01–10
```

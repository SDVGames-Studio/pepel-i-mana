# РЕФЕРЕНСЫ-СТИЛЬ — визуальный ориентир по референсам «для Z.ai»

> Не игровой модуль, а справочник стиля: выжимка из просмотра всех ~92
> картинок папки «для Z.ai» (2026-10-29, просмотрен каждый файл).
> Папка с референсами лежит в корне проекта, **вне git и экспорта**
> (`.gitignore` + `.gdignore`); рецепты восстановления — в `AGENTS.md`.
> Для будущих аспектов: сначала этот док, при работе — открыть сами
> эталонные файлы (имена — хэши, см. раздел «Файлы-эталоны»).

## 1. Суть: два режима одного мира

Референсы складываются в два чередующихся режима — игра должна уметь оба:

- **«Быт»** — тёплый жилой город: солома и черепица (#D9B36A, #A0522D),
  тёплое дерево (#4A3220), цветы и огороды, мягкий дневной свет.
  Текущий луга-город v1.32 уже в этой точке.
- **«Мрак»** — обветшалость и опасность: мох и ржавчина поверх камня,
  гнилые доски, кость на зелёном, кроваво-красные (#8E1B24/#8B1A1A) и
  ядовито-зелёные (#6a9a3a) акценты на глухом сине-сером (#3C4A52,
  #2A3644). Это данжи, кладбище, проклятые места, эпик-арены.

Мастер-гамма (приглушённая, «пасмурная», без кричащих цветов):
болотно-зелёные #4a6b3a/#6f8f4f, серо-синий камень #5a6470/#8a94a0,
бурая земля #5a4a38/#7a6a52, вода #1a6a78 → #123a4a; акценты —
ржаво-оранжевый #c05a2a, красный опасности, золото-орнамент #b89a4a.

## 2. Пять сквозных приёмов (взять везде)

1. **Контакт с землёй**: у каждого объекта тёмная подложка-тень «каплей»
   или «юбка» травы/песка у основания — отделяет пропс от тайла
   (город, природа, скалы).
2. **Кромка в 2–3 тона**: тёмный «срез» + светлая верхняя грань +
   бросаемая тень (скалы, стены); для воды — светлый мель-пояс →
   основной тон → тёмная глубина (+ тонкая белая линия прибоя/пены
   только в местах возмущения).
3. **Износ как оверлей**: мох, трещины, ржавчина, «наползающая» трава
   поверх базовой кладки — дешёвый слой поверх уже существующих тайлов,
   даёт «пепельность» и возраст (город, данж, руины).
4. **Свет-якоря**: на тёмной карте — несколько тёплых (#FFD876 факелы,
   фонарь героя) и/или холодных (#4FC3F7 лужи/пропасти) пятен; светящиеся
   глазницы/алтари отмечают цель и босса (данж, эпик).
5. **Силуэт и масса**: читаемый пухлый силуэт с крупной нижней массой у
   существ; один гигантский объект-«локомотив» (скелет, череп) как центр
   эпик-арены с радиальными тропами к нему.

## 3. Что брать по категориям

### Город, поселение (25 файлов)
Серии «один тип — 6 вариантов» (башни, избы, мосты, лавки): варианты
зданий = смена материала крыши + пристройки, не новые модели. Модульные
каменные стены (прямой/угол/врата с башенками) — основа обстройки.
Рыночные тюки/бочки/фонари/колодцы — плотность «жизни» на площади.
Эталоны: обветшалый хутор с сеткой (4edb4f2d — проверено: рисованный
top-down «Wanderer's Den», кровь/разрушение для мрачного быта), пиксельный
лист славянских церквей/ратников с 16-цветной палитрой (по разбору,
сверить файл при работе), мрачная шахта (c63e6fd2). Чужеродное:
скриншоты мобильных игр с HUD (983f61ba, dc6ccd4b — только тайлы, не UI).

### Природа и тайлы (19)
Кромки трава↔земля «зубчатыми пятнами» — ложится на текущий dual-grid
(d4a31bda — там же магические плитки с рунами). Подложка-земля с
камешками под кустами/пнями. Мшистые брёвна/коряги (cc5ac61d) — готовый
профиль пропсов славянского леса; дуплистый мёртвый пень (5b24cfae).
Палитра запечённых тайлов — пыльно-бурая, не сочная (0138e332).
Чужеродное: фото брусчатки/пней (60157199, e847cde5), яркая мультяшность
(af6632, a6766b), акварельные деревья строго сбоку (d996338d — только
виды/сезоны, не угол).

### Скалы (6)
Трёхтоновая кромка обрыва (см. приём 2) + «юбка» зелени у подножия;
модульные утёсы из повторяемых кусков фасада с травяными «шапками»
(035a333a); валуны на лугу чистым top-down (b3421be4); каньон с рекой —
кромка обрыва+воды в одном кадре (9b132112). Палитра серо-синего камня
с редкой зеленью сверху отличает скалы от серых дорог.

### Вода (10; 3 файла .jfif — просмотрены через конвертацию)
Кромка в 2–3 тона + круги ряби вокруг камней/лилий (a602a024 — мрачный
пруд со скелетом, прямой референс тона игры). Камыши/осока и лилии
«втыкаются» в кромку и маскируют границу вода/земля (ymPrI2 — пруд с
пирсом, богатейший по деталям). Пена только у водопадов и валунов
(6a5ca449). Тёмная река между бурыми берегами (images (1).jfif — очень
в тон; J8nDXD/images.jfif — тёмный лесной пруд). Чужеродно: стоковый
векторный тайлсет (pixel-art-tile-set…webp — только схема кромок).

### Данж, биомы и мир (15)
Схема света «тёплый фонарь + холодные сине-бирюзовые лужи/пропасти»
(a8ea4e27) — продолжение текущего света героя. «Пепельная порча»:
красно-чёрные потёки/трещины поверх кирпича как оверлей заражённых зон
(5f017950 — вместе с 666f6b4e ближайший ориентир композиции уровня).
Мох/трава, наползающие на камень скруглёнными пятнами, — мягкие переходы
биомов (0d1fe2dc, 14c0089b). Рунные круги на полу — интерактивные точки.
Чужеродное: фото макетов и фото-атлас текстур (69205152, 9e9da16e,
5e5c7177 — только идеи форм).

### НПС, герой (5)
Один силуэт — палитровый своп под стихии/биомы (25 жаб-вариаций,
59985d98) — принцип бестиария и жителей. Атака дуговым «шлейфом-веером»
(a9ffc303). HP-бар с каменной рамкой и «пепельной гнилью» (97493039 —
готовый UI-референс, в тон названию игры). Броня героя: глухой шлем с
единственной светящейся щелью. Чужеродно: мультяшный концепт брони
(a022138e — только силуэты).

### Эпик-локации (3)
Формула арены: один огромный силуэт (скелет короля-великана в короне,
череп дракона с горящими глазницами) + концентрические обходные тропы +
свет-якорь в центре; кость как белые фрагменты на зелёном; виньетка
тёмного леса по краю вместо стен (4985c6ba, 84542a38). Техника —
живопись: переносить композицию и палитру, адаптировать под дизеринг.

### Глобал мир (6)
Гекс-сетка с иконкой-landmark в ключевых гексах (b8b89f08 — полный
справочник биом-гексов с застройками; 76b0d14c — «живая» карта на
пергаменте). Тёплый пергаментный фон #D9C49A под затемнёнными
неоткрытыми областями — сочетается с туманом войны. Готический сет
построек (08d4f67f) — источник силуэтов иконок локаций. Чужеродно:
AI-3D-рендер долины (ed6b0caa — только палитра).

### Кладбища (2)
Комбинаторика надгробий «камень + мох + скол + крест» на булыжном
основании (353542ee — библиотека форм). Проклятое дерево-босс: чёрный
ствол, кроваво-красная крона (6499ce9c) — красная листва как маркер
опасности на сером фоне. Фон ночных зон — глухой сине-серый, не чёрный.

### Корень папки (1)
88df0c76 — руины/стены/надгробия серии EV GANIN: кладка из неровных
блоков с мхом сверху вниз, орнаментальные плиты-идолы, «растение
пробивается через конструкцию» — один из самых ценных для руин.

## 4. Правила использования агентом

1. Перед визуальной задачей — прочитать этот док; для аспекта открыть
   2–4 эталонных файла его категории (имена в разделе 3) и держать
   мастер-гамму раздела 1.
2. Новые спрайты/тайлы — через существующие генераторы (`tools/make_*.py`)
   в текущей технике (запечённые текстуры + дизеринг + блобы); референс
   задаёт палитру, кромки и композицию, а не смену техники.
3. Атрибуция «эталонных» файлов сделана по просмотру, имена — хэши;
   перед использованием открыть файл и сверить содержимое.
4. Новые референсы от заказчика просто кладутся в папку (она вне git);
   после существенного пополнения — дополнить этот док.
